# ADR-001 — Revisión independiente como capacidad, no como nueva autoridad

**Estado:** propuesta implementada, pendiente de validación externa del aislamiento del host.

## Contexto

El repositorio ya dispone de trazabilidad, glosario, memoria selectiva, decisiones, Groma y límites WIP en `backlog-agile-workflow`. Duplicar estos componentes para Goldfish produciría acoplamiento, fuentes incompatibles y gasto operacional.

## Decisión

Crear `goldfish-review` autocontenida, con rúbricas y herramientas puras de validación y agregación. La delegación de subagentes es un efecto del **host**, no del router ni de los validadores. Sin contexto fresco y permisos readonly verificables, NOT_RUN/INCONCLUSIVE. Reutilizar Backlog.md, Git y Groma como autoridades existentes. El comparador de fingerprints nunca declara divergencia semántica de manera automática. El hook Claude opcional emite solo una sugerencia.

## Consecuencias

Skills portables y sin dependencia del plugin EGM oficial. Los smokes reales por host se realizarán solo donde exista delegación nativa; no son equivalentes a los tests del parser. No se genera una tarea, decisión aceptada ni cambio de WIP desde una opinión de agente.
